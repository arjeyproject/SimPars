# جریان خرید شماره مجازی

مسیر خرید شماره مجازی در SimPars:

`منوی اصلی → خرید شماره مجازی → انتخاب پلتفرم → انتخاب کشور → پیش‌فاکتور → پرداخت/کیف پول → دریافت شماره`

## کاتالوگ واقعی

پلتفرم‌ها مستقیماً از کاتالوگ `5SIM /guest/prices` ساخته می‌شوند. کشورها فقط وقتی نمایش داده می‌شوند که موجودی و قیمت معتبر داشته باشند. فهرست قیمت و موجودی هنگام ورود به کشور و دوباره پیش از خرید بررسی می‌شود؛ بنابراین نمایش یک گزینه تضمین‌کنندهٔ موفقیت خرید نیست.

## چیدمان تلگرام

برای هر کشور سه دکمه در یک ردیف وجود دارد: کشور و پرچم، قیمت، و خرید. تلگرام برای دکمه‌های Inline پس‌زمینهٔ رنگی سفارشی ارائه نمی‌کند، بنابراین ستون‌ها با نشانگرهای `🟩`، `🟦` و `🟧` و سبک‌های موجود API از هم تفکیک می‌شوند. هر سه دکمهٔ ردیف یک callback مخصوص همان محصول و کشور دارند.

## ایمنی پرداخت

خرید کیف پول ابتدا یک سفارش محلی `PENDING` و رزرو اتمیک موجودی ایجاد می‌کند. پاسخ نامشخص provider باعث خرید مجدد نمی‌شود؛ خطاهای قطعی با `refund_reserved_order` برگشت می‌خورند. ثبت نهایی سفارش فقط با شرط `PENDING` و بدون `fivesim_id` انجام می‌شود تا تپ‌های تکراری و callbackهای تکراری دوباره پول کم نکنند.

پرداخت مستقیم نیز پس از تأیید پرداخت، قیمت و موجودی provider را دوباره resolve می‌کند و در صورت خطای قطعی، مبلغ را به کیف پول برمی‌گرداند.

## ناوبری

دکمهٔ `🔙 بازگشت` از فهرست کشورها به فهرست پلتفرم‌ها برمی‌گردد و دکمهٔ منوی اصلی در هر دو سطح حفظ شده است.
