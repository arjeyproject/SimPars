# چک‌لیست آماده‌سازی فروش SimPars

## قبل از فروش

1. از `data/simpars.db` و `.env` بکاپ بگیر.
2. در `/admin`، API پنج‌سیم را ثبت کن و موجودی پنل را ببین.
3. در `/admin`، مرچنت زیبال را ثبت کن. برای تست اول Sandbox را روشن کن.
4. نرخ تبدیل، سود، حداقل و حداکثر شارژ را تنظیم کن. نرخ را با واحد تومان بررسی کن.
5. در صورت استفاده از نگهبان نرخ، کلید و URL را در `قیمت‌گذاری و مالی ← نگهبان نرخ دلار` ثبت و تست کن.
6. برای callback خودکار، آدرس عمومی HTTPS را در `درگاه زیبال` ثبت کن، مثل `https://pay.example.com/zibal/callback`.

## تست واقعی کنترل‌شده

```bash
cd /opt/SimPars
python3 scripts/preflight.py
systemctl status simpars --no-pager
journalctl -u simpars -n 100 --no-pager
curl -fsS http://127.0.0.1:8080/health
```

سپس در Sandbox یک شارژ کوچک انجام بده و مطمئن شو فقط یک بار به کیف پول اضافه می‌شود. بعد API پنج‌سیم را با ارزان‌ترین سرویس دارای موجودی امتحان کن: شماره باید بیاید، کد SMS باید خودکار برسد، و با لغو یا timeout وجه فقط یک بار برگردد.

## بازکردن فروش

بعد از تست موفق، Sandbox را خاموش کن، یک پرداخت واقعی کوچک انجام بده، سپس خرید را تست کن. لاگ‌های زیر را در چند دقیقه اول باز نگه دار:

```bash
journalctl -u simpars -f
```

اگر نرخ لحظه‌ای قدیمی شود، نگهبان فروش را متوقف می‌کند تا ضرر ایجاد نشود. اگر نرخ API نداری، نرخ پنل دستی fallback است و مسئولیت به‌روزرسانی آن با مدیر است.

## نکته مهم callback

درگاه باید بتواند از اینترنت به پورت callback برسد. بهتر است callback پشت دامنه HTTPS و reverse proxy باشد، نه IP خام. اگر callback در دسترس نیست، کاربر هنوز می‌تواند دکمه `پرداخت کردم` را بزند و ربات پرداخت را از زیبال verify می‌کند.
