# راه‌اندازی زرین‌پال در SimPars

1. در زرین‌پال یک درگاه بساز و **Merchant ID** سی‌وشش‌کاراکتری را بردار.
2. در Cloudflare برای دامنه یک رکورد `A` بساز و callback را روی HTTPS قرار بده:
   `https://prostoreshop.site/zarinpal/callback`
3. ربات را ری‌استارت کن و در تلگرام `/admin` را بزن.
4. از بخش «تنظیمات درگاه زرین‌پال»، مرچنت را ثبت کن.
5. یک شارژ کوچک تست کن. پس از بازگشت از درگاه، کیف پول به‌صورت خودکار شارژ می‌شود و callback دوباره‌پرداخت را کنترل می‌کند.

**نکته امنیتی:** Merchant ID را فقط در پنل مدیریت ربات وارد کن و داخل GitHub یا فایل عمومی قرار نده. API زرین‌پال در سرور اجرا می‌شود، نه در مرورگر کاربر.

پرداخت فعلی برای شارژ کیف پول است؛ پس از شارژ، کاربر شماره مجازی را از بخش خرید انتخاب می‌کند. تحویل مستقیم شماره در همان checkout نیازمند افزودن کشور/سرویس به فاکتور پرداخت است و عمداً جدا نگه داشته شده تا پرداخت اشتباه باعث خرید خودکار شماره نشود.
