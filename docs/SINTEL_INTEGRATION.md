# راهنمای سرویس‌های شبکه‌های اجتماعی

نام فایل برای سازگاری با نصب‌های قدیمی حفظ شده است، اما ارائه‌دهنده فعال SimPars اکنون **پنلیکس** است. هیچ سفارش یا سابقه مالی قدیمی حذف نمی‌شود.

راهنمای کامل تنظیم کلید، واحد نرخ، همگام‌سازی، قیمت‌گذاری امن و Docker در [PANELIX.md](PANELIX.md) قرار دارد.

کلید فقط از مسیر «پنل مدیریت» و بخش «مدیریت پنلیکس» ثبت می‌شود. پاسخ خالی یا نامعتبر API جایگزین کاتالوگ معتبر قبلی نمی‌شود و درخواست ثبت سفارش پس از تایم‌اوت تکرار نخواهد شد.
