# راه‌اندازی پنلیکس در SimPars

## تنظیم کلید

ربات را اجرا کنید، وارد «⚙️ پنل مدیریت» و سپس «⚙️ مدیریت پنلیکس» شوید. از «🔑 تنظیم کلید API» کلید را ارسال کنید. کلید در پیام‌ها و گزارش‌ها نمایش داده نمی‌شود و پیام حاوی آن حذف می‌شود.

## نرخ و قیمت‌گذاری

پنلیکس فهرست زنده را با `POST https://panelix.ir/web/api/v1` و `action=services` می‌دهد. تا وقتی واحد نرخ (`per_1000` یا `per_order`) و ارز در پنل مدیریت ثبت نشوند، سرویس‌ها وارد کاتالوگ بررسی‌شده نمی‌شوند و خریدشان عمداً متوقف است. اگر ارز دلار باشد، نرخ تازه و معتبر نوسان نیز لازم است.

## همگام‌سازی

«📥 دریافت آخرین سرویس‌ها» همگام‌سازی دستی و «🔄 بروزرسانی قیمت‌ها» همان مسیر محافظت‌شده را اجرا می‌کنند. همگام‌سازی خودکار طبق فاصله تنظیم‌شده انجام می‌شود. پاسخ خالی، ناقص یا خطای شبکه کاتالوگ معتبر قبلی را حذف نمی‌کند. تغییرات محلی نام نمایشی، ترتیب، سود و نمایش در رکورد سرویس حفظ می‌شوند.

## سفارش و خطا

برداشت کیف پول قبل از سفارش اتمیک است. درخواست `add` تکرار نمی‌شود. اگر پاسخ ثبت سفارش در تایم‌اوت نامشخص باشد، سفارش در وضعیت بررسی می‌ماند و استرداد خودکار انجام نمی‌شود. سفارش‌های قدیمی و جدول‌های قبلی حذف یا منتقل نمی‌شوند.

## Docker

```bash
docker compose build
docker compose up -d
# لاگ‌ها
docker compose logs -f simpars
```

قبل از فعال‌سازی فروش، یک همگام‌سازی دستی، بررسی واحد/ارز نرخ، تست اتصال و یک سفارش آزمایشی با مبلغ کم انجام دهید. موجودی پنلیکس با کیف پول تومانی کاربران جداست.
